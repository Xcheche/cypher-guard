# Google reCAPTCHA — Fortitech Project Notes

## Overview
reCAPTCHA protects the email/password login form only.
"Login with Google" (OAuth) is a separate flow and does NOT use reCAPTCHA.

Flow:
1. User submits login form + completes reCAPTCHA widget
2. LoginForm.is_valid() verifies token with Google (server-side)
3. If valid → authenticate() runs
4. Google OAuth button → goes to Google directly, never hits LoginForm

# =============================================================================
# 9. Troubleshooting
# =============================================================================
# "Invalid site key" or captcha not loading:
#   - Domain in browser URL not listed in reCAPTCHA admin
#   - Wrong RECAPTCHA_PUBLIC_KEY in .env

# Login always fails with captcha error:
#   - Wrong RECAPTCHA_PRIVATE_KEY in .env
#   - Keys swapped (public/secret reversed)

# Django DisallowedHost:
#   - Add hostname to ALLOWED_HOSTS in .env

# reCAPTCHA works on localhost but not local.test:
#   - Add local.test to /etc/hosts AND reCAPTCHA admin AND ALLOWED_HOSTS
#   - Browse http://local.test:8000 not 127.0.0.1
